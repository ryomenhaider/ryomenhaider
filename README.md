## What I Care About

A lot of data work stops at “it works on my machine” or “the model got decent accuracy.” I’m more interested in the parts that usually get neglected:

- Making data ingestion and validation actually robust  
- Designing systems that can be reused instead of rewritten  
- Treating data quality and schema consistency as first-class concerns  
- Building platforms that other people (or future versions of myself) can actually depend on  

I prefer boring, reliable systems over flashy demos.

## Current Work

### Hermes Data Platform
An open-source data platform focused on acquiring, validating, normalizing, storing, and serving datasets from multiple external sources.

The goal is simple: create a single, trustworthy data layer that downstream applications and analysis can rely on. Hermes handles connectors for economic, financial, geopolitical, and other structured data, along with validation, deduplication, schema management, and clean interfaces for both ingestion and serving.

It’s designed as a reusable Python package so the same data layer can be used across different projects instead of being rebuilt each time.

### Sentinel
A financial intelligence platform for market data analysis, anomaly detection, and forecasting.

Sentinel is built to move beyond one-off scripts. It focuses on proper data ingestion pipelines, repeatable analysis, and production-oriented backend components (FastAPI + PostgreSQL). Machine learning is used where it makes sense — particularly for anomaly detection and forecasting with tools like Prophet and XGBoost — but always as part of a larger, maintainable system rather than the centerpiece.
